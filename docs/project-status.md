# Data-Centric RSI 项目状态

更新日期：2026-10-29。本文件概述两个独立研究方向及总项目的整合状态，不合并双方数据集、环境或实验协议。

## MLE-Aladdin

- **范围：** 少样本生成任务中的数据合成、自动清洗、反馈选择，以及利用反馈更新后续数据构建策略的递归流程。
- **实现：** `projects/aladdin/experiments/` 包含合成、清洗、反馈采集/选择、评价和多轮 RSI runner；`scripts/` 提供 PRISM、HelpSteer2 与 LCCC 数据准备、审计和结果分析工具。
- **实验状态：** PRISM 多轮流程已有 pilot 配置；尚需在目标服务器完成模型/API/GPU 端到端验证并据此冻结确认性实验规模。LCCC 智能联想代理任务已有数据构造和协议，尚无实验结果。
- **验证：** 同步后的 Aladdin 项目在本地 CPU 环境通过 74 项测试。这说明当前软件测试通过，不代表实验效果已得到验证。
- **发布：** 上一版已发布至 `Mars-aliens/Data-Centric-RSI` 的 `main`；本次按本地版本同步的变更尚未推送。
- **证据边界：** Qwen3-32B 模拟反馈不代表真人意见或人工耗时；PRISM 结果不能外推到 LCCC 输入法场景。正式最终评测前，final-test 标签保持封存。

## MLE-LEGO

- **范围：** 改进 Data System 的整体运行方法，重点研究候选修改隔离、经验生命周期治理和基于延迟反馈的版本选择，三个技术点共同保障长周期稳定运行。
- **实现：** 已具备 HelpSteer2 受控流式任务、固定流水线、候选安全门、隔离运行接口、经验生命周期和版本选择框架；技术二、三及跨技术真实运行集成仍在开发。
- **当前阶段：** 先执行 10～20 周期 pilot，验证数据、模型、容器隔离、反馈时序、状态恢复和资源成本，再根据结果决定正式实验规模。
- **验证边界：** 本地自动化测试通过不等于服务器真实模型和数据上的端到端验证。正式周期性候选调度、多候选恢复、故障压力测试及多随机种子评估尚未完成。
- **发布：** 当前代码位于 `projects/mle-lego/`，已发布至总仓库 `main` 分支。

## 总项目

- 总项目负责协调两个方向，不合并代码，也不将一方测试结果当作另一方结果。
- 总项目仓库包含 `projects/aladdin/` 和 `projects/mle-lego/` 两个可独立安装、测试和执行的项目目录。
- Aladdin 与 MLE-LEGO 在总仓库中分别维护；更新某一方向时，只同步该项目目录及必要的总仓库入口文档。
- **发布：** 总项目 `main` 分支已发布至 `Mars-aliens/Data-Centric-RSI`；最近已同步项目目录和文档更新。
- 尚未抽取共享代码。只有双方出现具体整合需求后，才定义并测试共同接口。

## 协调待办

1. 两个项目保持目录、依赖和实验协议相互独立。
2. 各项目基于已记录的代码版本和协议开展实验，并将经过审查的结果更新到对应状态文档。
3. 明确跨项目 API 和共同评估要求后，再评估是否抽取共享代码。
