## MLE-LEGO

- **实现：** 技术一包含独立修改与严格的依赖感知联合修改、提案校验、候选评估、held-in 接受、held-out 报告、回滚、检查点恢复、服务器运行器、审计脚本和测试。技术二（可执行经验复用）及技术三（连续反馈选择）已有模块边界文档，尚未实现。
