# MLE-LEGO 固定技术点

状态：**方向已冻结**
版本：`technical-points-v1`
适用范围：MLE-LEGO 的研究方向、实验协议、实现说明和对外介绍。

以下三个技术点的名称与定义为本项目统一版本，后续文档和实现说明应沿用，不另行改名或改变其研究含义。实现范围、实验参数和代码结构可以逐步细化，但不能与这三个定义冲突。若要改变技术点本身，须由项目负责人明确重新决策并发布新版本。

1. **数据策略隔离验证**：隔离试验候选数据处理策略，确认对数据质量和下游训练的影响后再接纳，降低失败更新干扰稳定流程的风险。
2. **数据经验持续治理**：跟踪经验与 Skill 的来源、适用条件和失效证据，及时更新或停用，减少过时规则长期误导数据处理。
3. **延迟反馈下的数据策略演化**：将反馈关联到产生该反馈的数据与系统版本，依据多轮效果调整策略，减少延迟反馈导致的错误判断。

三者共同面向 Data-Centric AI 中的数据处理与数据策略，并分别处理候选策略更新风险、长期积累经验风险和延迟反馈决策风险，保障 Data System 长周期稳定执行。递进关系为：**隔离验证单次策略更新 → 持续治理数据经验 → 根据延迟反馈演化数据策略**。

本文件是上述名称和定义的唯一权威来源。研究范围、README、实验协议、服务器手册和代码注释如需引用技术点，应链接或沿用本文件中的表述。
