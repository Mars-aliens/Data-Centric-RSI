# 技术一实验

技术一是“安全自进化与故障隔离”。先按[工程协议](protocol-v1.md)完成 `local_shadow` 部署 smoke，再运行 10～20 周期 pilot，依据稳定运行、故障隔离、状态恢复和资源成本决定后续实验规模。该 backend 只执行受限数据策略的可信 runner，不提供任意代码或容器级隔离。

当前步骤：先完成 4 周期部署 smoke，再按[执行手册](../../docs/technology-one-safe-evolution-runbook.md#10-20-周期-t1-pilot-命令)运行 10～20 周期 pilot。Pilot 结束后，根据稳定运行、候选隔离、恢复能力和资源成本确定后续正式实验规模。周期性候选调度和多候选恢复完成前，不启动正式递归实验。

本目录保存实验协议、审计摘要和外部证据包的链接及校验值。HelpSteer2 数据、模型权重、profile、日志、运行结果和凭据不得提交到仓库。
