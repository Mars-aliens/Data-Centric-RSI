# Aladdin Experiment Modules

This package contains Aladdin's feedback selection, requirement-state,
dataset-audit, integrated-pipeline, HelpSteer2, HH-RLHF, and downstream Qwen
validation modules.

The public entry points are documented in the repository root
`README.md` and in `integrated_pipeline/SERVER_HANDOFF.md`. All input and
output paths are supplied by the operator; this source tree does not contain
datasets, model weights, or run outputs.
