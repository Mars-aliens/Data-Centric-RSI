# 人工反馈成本与主观评价：文献笔记

**核对日期：** 2026-10-22
**用途：** 为 Aladdin 的反馈协议提供参考。这是限定范围的文献笔记，不是系统性综述。

## 核心结论

已有研究并不能让主观的人类偏好变成客观真理，主要是提高反馈使用效率，或显式建模标注者分歧。因此，Aladdin 更稳妥的主张不是“找到了客观正确答案”，而是“在明确的目标人群和相同人工时间预算下，流程带来更好的测量结果，或以更少人工时间达到预先设定的结果”。

需要分开回答三个问题：

1. **下一条该请人标注什么？** 主动偏好学习、不确定性采样和期望信息增益关注查询效率。
2. **如何表示不同人的看法？** 以标注者为中心或 perspectivist 的方法保留分歧，而不是强行形成共识。
3. **哪些反馈可以自动化？** AI feedback 方法可能减少直接人工标注，但会引入模型判断误差。除非实际测量人工分钟，否则不能据此声称节省了人工时间。

|---|---|---|---|
| Christiano 等，**Deep Reinforcement Learning from Human Preferences** (NeurIPS 2017) | 从轨迹片段的人工成对比较学习奖励模型，并用其训练策略。 | 两个条目回答同一任务时，成对比较是可操作的反馈单位；按比较预算报告效果。 | 研究环境是机器人/RL，不是生成数据流程。论文的比较次数不能直接换算成当前任务的人工时间。[论文](https://arxiv.org/abs/1706.03741) |
| Ouyang 等，**Training Language Models to Follow Instructions with Human Feedback** (NeurIPS 2022) | 收集示范和模型输出排序，拟合奖励模型并使用 PPO。 | 给标注者看具体输出和候选比较，不要求一开始就写出完整 rubric。 | 展示的是 RLHF 流程，不是减少标注耗时的主动查询策略，也不递归更新合成/清洗策略。[论文](https://arxiv.org/abs/2203.02155) |
| **Deep Bayesian Active Learning for Preference Modeling in Large Language Models** (NeurIPS 2024) | 使用贝叶斯偏好不确定性选择有信息量的比较。 | 纳入基于不确定性/信息量的主动偏好基线，不要只和随机选择比较。 | 目标是提高偏好模型查询效率；本身不能证明端到端人工分钟下降，也不能证明递归合成训练数据更有效。[会议论文集](https://doi.org/10.52202/079017-3749) |
| **MAPLE: A Framework for Active Preference Learning Guided by Large Language Models** (AAAI 2025) | 利用 LLM 指导主动偏好学习并优先安排比较。 | 可作为较新的主动选择方法参考，检查是否适合作为强对照或改造方案。 | 未匹配具体查询策略、数据和实现前，不要声称复现。论文中的标注预算不自动等于 Aladdin 实测评审时间。[会议论文集](https://doi.org/10.1609/aaai.v39i26.34964) |
| **Annotator-Centric Active Learning for Subjective NLP Tasks** (EMNLP 2024) | 将标注者及其主观判断纳入主动样本选择。 | 数据模型保留标注者身份/视角；若 Aladdin 研究个性化，不能把目标用户反馈折叠成全局多数标签。 | 研究对象是主观 NLP 标注，不是迭代合成和下游模型训练。[ACL Anthology](https://aclanthology.org/2024.emnlp-main.1031/) |
| Fleisig 等，**When the Majority is Wrong: Modeling Annotator Disagreement for Subjective Tasks** (EMNLP 2023) | 研究主观任务中的标注者分歧，指出多数标签可能掩盖重要视角。 | 报告分歧和标注者级结果，不要把多数投票描述为客观 ground truth。 | 没有解决标注成本，也没有研究 Aladdin 的数据生成循环。[ACL Anthology](https://aclanthology.org/2023.emnlp-main.415/) |
| Bai 等，**Constitutional AI: Harmlessness from AI Feedback** (2022) | 在 harmlessness 任务中用书面原则以及 AI critique/revision 或偏好反馈，减少直接人工标签依赖。 | 可将 AI feedback 作为独立低成本反馈来源研究，并单独审计其错误。 | 它把判断转移给模型和固定原则，不能证明 AI feedback 能捕捉不断变化的用户意图，也不能证明实测人工时间减少。[论文](https://arxiv.org/abs/2212.08073) |

## 这些研究如何处理成本

- **同一输入的回答优先用成对比较。** 两个具体回答之间做选择，通常比开放式质量打分更容易操作。Aladdin 还须允许平局、两者都不合适和无法判断。
- **主动挑选查询。** 随机是对照；不确定性或贝叶斯主动偏好学习是成熟方法族；Aladdin 的单位评审成本影响力是拟议方法。分别按累计标签数和实测人工分钟比较。
- **复用反馈。** RLHF 训练奖励/偏好模型，让每条标注可影响不止一个输出。Aladdin 也必须明确说明反馈如何改变有版本记录的合成/清洗策略，或成为经人工确认的示范。
- **自动化必须配审计。** AI feedback 可作为一个独立实验组，但不同提示词/模型之间的意见分歧不等于正确性。应由独立人员审计保留和拒绝的样本，并计入审计耗时。
- **保留不同视角。** 研究个性化要求时，反馈应与用户关联；研究群体结论时，应抽样目标群体、收集独立评分，并报告分歧，而不是假装偏好只有一个客观标签。

## 建议的 Aladdin 验证方式

### 历史标签回放

只在 PRISM/HelpSteer2 标签确实对应查询条目时使用。标签在查询选中前保持隐藏。比较：

1. 随机选择。
2. 贝叶斯/不确定性主动偏好选择。
3. 作为简单诊断基线的分歧选择。
4. Aladdin 单位评审成本影响力选择。

报告标签数量变化下的 held-out 偏好模型表现和选择策略诊断。该实验只能说明历史标签回放效率，不能说明真实用户耗时下降，也不能说明用户对新生成样本的偏好。

### 真人标注研究

生成新候选后，先邀请目标人群成员参与小规模计时试验。随机、不确定性和 Aladdin 选择方法在固定人工分钟预算下比较。记录实际评审时间、澄清/编辑时间、`cannot_judge` 比例，以及有多少已审样本真正改变了带版本的合成决策。另用独立且盲测的人工评价集测量输出质量。

主要成本效果指标：

- 相同累计人工分钟下的输出偏好质量；
- 达到比较前冻结的 development 目标所需人工分钟；
- 输出质量-人工时间曲线下面积；
- 分别报告生成、judge、训练和人工标注成本。

目标质量和评价集必须在查看 final-test 标签前固定。若目标人群没有被抽样，就应说明结果只适用于特定用户。人工评分代表测得的人类偏好，不是客观真理。
