# Aladdin 协作说明

Aladdin 是更大的 Data-Centric RSI 项目的一部分。本项目只维护 Aladdin 当前研究方向，不要混入 MLE-LEGO 或其他子项目的代码和实验。

## 协作约定

- 修改研究范围或实验方案前，先与项目负责人直接沟通。
- 按 `README.md` 中的流程推进：数据合成、数据清洗、选择代表性样本收集人工反馈，并由递归更新循环将三者连接起来。
- 数据集、模型权重、凭据、服务器配置、日志和运行产物保留在项目目录之外或 Git 忽略目录中。
- 将实验结果视为确认性结果之前，须在当前实验文档中记录方法、数据集及版本、模型及版本、人工和计算预算、评价集与数据泄漏检查。

两位协作者直接沟通和交接即可，不要求通过 GitHub issue 管理执行流程。
